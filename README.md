# Projeto Desafio Simfrete Previsão do Tempo

Tecnologias utilizadas

Angular 19
Node 22
TypeScript

## Acessando o projeto

Na raiz do projeto execute ``npm instal`` e após ``ng serve``

O projeto irá subir em :

http://localhost:4200/
